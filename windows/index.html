下载安装包（0.3.0）

2026-11-05 发布 · Windows 10、11（64 位）· 约 3MB · 装在当前用户下，不要管理员权限

装的时候

  • 安装包还没做代码签名，Windows 可能弹「Windows 已保护你的电脑」：点「更多信息」，再点「仍要运行」。
  • 第一次打开时，Windows 防火墙会问要不要让饭耳在专用网络上通信：点「允许」，iPhone 才连得进来。
  • 想一开机就开着：在托盘的饭耳图标上点右键，勾「登录时打开饭耳」。

让电脑帮 iPhone 转写

最推荐在线转写：在 iPhone 饭耳的「语音转文字」里选在线服务，转得最准。想免费、录音不出你的电脑，可以让这台电脑本地转写：在电脑上的饭耳里选一档，点「下载并装好」。

  • 装好后在电脑上点「显示配对二维码」，用 iPhone 相机扫码，在饭耳里确认。
  • 之后新录音交给这台电脑转写：电脑开着、和手机连着同一个 Wi-Fi 时转，不在就等它。录音只在手机和你的电脑之间加密传，不经过开发者的服务器。
